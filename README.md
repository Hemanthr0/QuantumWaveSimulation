# Quantum Wave Simulation

A Python-based simulation of 1D quantum wave packet evolution using the Crank–Nicolson method.

## Features
- Choose from **Free Particle**, **Harmonic Oscillator**, **Double Well**, or **Barrier Potential**.
- Real-time animation of |ψ(x)|² evolution.
- Expectation value analysis of ⟨x⟩ and total energy ⟨E⟩.
- Fully modular structure (easy to extend).

## Usage

```bash
pip install numpy matplotlib
python src/main.py
```

Then follow the on-screen menu to choose the potential.
